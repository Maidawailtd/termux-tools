# Termux Hacking Tools Installer

![Banner](banner.png) <!-- Add a banner image if you have one -->

This repository contains a script to install popular hacking tools on Termux. It also includes pre-configured wordlists for Hydra and a Metasploit payload generator.

**Created by MGLINK**

---

## Tools Included
- Nmap
- Hydra
- SQLMap
- Metasploit
- Social Engineer Toolkit (SET)
- UFONet

---

## Features
- Custom installation banner.
- Pre-configured Hydra wordlists (`passwd.txt` and `userslist.txt`).
- Metasploit payload generator script.
- Easy-to-use installation script.
